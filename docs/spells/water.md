# Water Element

Taught by **Nereus, the Water Sage** (near spawn).

| # | Skill | Key | Cast | Effect |
| - | ----- | --- | ---- | ------ |
| 1 | **Water Beam** | `1`, hold RMB | projectile | A fast, light bolt of water. Good for quick repeated shots. Base 22 dmg. |
| 2 | **Ice Shard** | select + hold RMB | projectile | A heavier frozen bolt. Base 28 dmg. |
| 3 | **Healing** | select + RMB | self | Restores the caster's health. |

Tuning in `SPELLS.water*` / `heal` in
[`apps/web/src/game/spells.ts`](../../apps/web/src/game/spells.ts).
